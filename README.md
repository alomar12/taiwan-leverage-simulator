# 台灣50正2再平衡模擬器 v1.5

## v1.5 新增

- 「① 實際資料回測」新增兩種模式：
  - 2014/10/31至今：實際0050＋實際00631L
  - 1999年至今：官方TAIEX＋校準模擬正2
- 新增「投資開始日期」選擇。
- 初始本金仍可在左側自由調整。
- 1999長期模式會顯示：
  - TAIEX大盤
  - 模擬正2
  - 2014/10/31後實際00631L
- 2014後另提供「模擬正2 vs 實際00631L」同起點校驗圖。

## 重要定義

1999–2013並不存在00631L。該段正2是以官方TAIEX每日報酬為市場路徑，
再套用2014年至今實際00631L相對理論每日2倍的偏差模型重建，因此屬研究／壓力測試。

2014/10/31後則可直接切換到實際00631L資料做真正歷史回測。

覆蓋 GitHub 中的 app.py、requirements.txt、README.md。
