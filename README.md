# 台灣50正2再平衡模擬器 v1.9

## 新增：投資期間最低資產統計

在「① 實際資料回測」及「⑤ 越跌越買策略」的統計區新增：

- 最低總資產
- 最低總資產發生日期
- 最低總資產當天的正2金額
- 最低總資產當天的現金金額
- 正2部位歷史最低值及日期
- 現金部位歷史最低值及日期

這可以直接看出策略最差時刻：
「總資產剩多少、其中正2多少、現金多少」。

同時也能確認：
- 正2曾經最低降到多少
- 現金是否曾經降到 0
- 各自發生在哪一天
