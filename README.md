
# 台灣50正2再平衡與股災壓力測試模擬器

## 目的
這個 Streamlit 程式用來比較：

- 100% 0050
- 自訂比例的 00631L（台灣50正2）＋現金
- 價格漲跌門檻再平衡
- 部位比例偏離再平衡
- 參數網格搜尋
- 2000 年網路泡沫與 2008 年金融海嘯壓力測試
- 依 2014/10/31 至今實際 00631L 與理論每日2倍的偏差，生成歷史模擬正2

## 模型重點
1. 2014/10/31 以後直接使用 00631L 實際日資料。
2. 0050：
   - Close 用於估計正2對「價格報酬」的偏差。
   - Adj Close 用於 100% 0050 的投資人總報酬比較。
3. 2008：
   - 使用 0050 價格報酬生成模擬正2。
4. 2000：
   - 因 0050 尚未上市，以 TAIEX 作為市場代理。
   - 這不是臺灣50的精確歷史，因此應視為壓力測試而非真實回測。
5. 模擬正2有三種：
   - 理論2倍：2 × 市場每日報酬
   - 校準平均：2 × 市場每日報酬 + 條件偏差模型
   - 波動狀態抽樣：再加入從2014年至今實際偏差殘差抽樣的蒙地卡羅路徑

## 安裝
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud
將 `app.py` 與 `requirements.txt` 放到同一個 GitHub repo，主程式選 `app.py` 即可。

## 建議使用流程
1. 先在「實際資料回測」測你想人工執行的策略。
2. 到「參數最佳化」搜尋一整片穩定區，不要只選單一最高CAGR參數。
3. 把候選參數放到「2000/2008壓力測試」。
4. 使用「波動狀態抽樣」跑 300–1000 條路徑。
5. 優先找：
   - 最大回撤可接受
   - Calmar 不差
   - 交易次數不過多
   - 鄰近參數也表現相似
   的「穩健區域」。

## 注意
- Yahoo Finance 資料可能偶爾受連線或限流影響。
- 00631L 是單日正向2倍產品，長期績效具有路徑依賴。
- 2000 年 TAIEX 代理與臺灣50成分不同，不能當作精準的00631L歷史績效。
- 程式是研究與風險測試工具，不是未來報酬保證。
