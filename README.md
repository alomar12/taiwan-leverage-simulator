
# 台灣50正2再平衡模擬器 v1.2

## v1.2 最大改版：本地歷史資料庫

本版不再於每次開啟網站時重新下載 1999 年至今全部資料。

平常流程：

1. Streamlit 啟動。
2. 直接讀取 `data/market_daily.csv`。
3. 0050 / 00631L 實際回測、參數最佳化、2000/2008 壓力測試全部使用本地資料。
4. 不會自動連 Yahoo Finance。

只有到「⑤ 資料管理」並按：

- `建立完整歷史資料庫`
- `只更新最新缺漏資料`

才會連網。

---

## 第一次部署方式

### 1. 將下列檔案全部上傳 GitHub

```text
app.py
requirements.txt
README.md
data/
  market_daily.csv
```

ZIP 內的 `market_daily.csv` 一開始只有欄位名稱，沒有歷史數據。

### 2. Streamlit 部署完成後

進入：

`⑤ 資料管理`

按：

`建立完整歷史資料庫`

程式會一次下載：

- TAIEX：1999 年至今
- 0050：2003/06/30 至今
- 00631L：2014/10/31 至今

### 3. 建立完成後

在同一頁按：

`下載最新版 market_daily.csv`

把下載的新檔案覆蓋 GitHub：

`data/market_daily.csv`

Commit changes。

之後 Streamlit 每次啟動就直接讀這份資料，不再需要重新抓 30 年行情。

---

## 日後更新

例如 GitHub 裡的資料到 2026/09/23：

1. 開網站。
2. 到「⑤ 資料管理」。
3. 按「只更新最新缺漏資料」。
4. 程式只重抓每個標的最後約 14 天至今天，用來補新交易日與修正晚到資料。
5. 下載最新版 `market_daily.csv`。
6. 覆蓋 GitHub 的 `data/market_daily.csv`。
7. Commit。

## v1.2 其他修正

- 第 0 個交易日固定顯示完整起始本金，不會先套一次報酬。
- 50% 正2 + 50% 現金時：
  - 正2 = 500,000
  - 現金 = 500,000
  - Portfolio = 1,000,000
- 保留 ETF 分割跳空自動偵測與修復。
- 參數最佳化完全使用記憶體中的本地資料，不重複抓網路。
- 保留：
  - 100% 0050 比較
  - 價格門檻再平衡
  - 比例帶再平衡
  - Pareto frontier
  - 2000 / 2008 壓力測試
  - 00631L 偏差模型
  - 波動狀態抽樣蒙地卡羅

## 為什麼用 CSV 而不是 SQL

目前資料量大約只會是數萬列，CSV 已足夠快，且你可以直接打開檢查。
若後續加入更多 ETF、分鐘資料或大量情境資料，再轉 SQLite / Parquet 會比較有意義。
